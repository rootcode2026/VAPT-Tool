# Getting Started

1. Secure your account — set a strong password and enable MFA in Settings → Security. 2. Understand your organization and project — organization is the tenant, project is the security boundary. 3. Create or select a project. 4. Add targets you are authorized to scan. 5. Run a scan (quick for fast, full for deep). 6. Review findings (severity, risk, evidence). 7. Explore assets and attack surface. 8. Review code/cloud/API security. 9. Generate reports. 10. Review compliance. 11. Use AI Analyst where enabled. 12. Configure monitoring.
